Enable Hardware Acceleration for Best Experience

This platform uses WebGL, CSS animations, and video — all of which require hardware acceleration to run smoothly. If the site feels laggy, animations stutter, or the 3D globe won't load, enabling GPU acceleration will fix it. Here's how for each browser:

  1. Open chrome://settings/system in the address bar
  2. Toggle "Use hardware acceleration when available" to ON
  3. Click Relaunch to restart Chrome

If still lagging: chrome://flags → search "WebGL" → set to "Enabled". Also check chrome://gpu — WebGL should say "Hardware accelerated".

  1. Open edge://settings/system in the address bar
  2. Toggle "Use hardware acceleration when available" to ON
  3. Click Restart

Check edge://gpu — WebGL status should read "Hardware accelerated". If it says "Software only", update your GPU drivers.

  1. Open about:config in the address bar
  2. Search for webgl.disabled and set it to false
  3. Search for gfx.webrender.all and set it to true
  4. Restart Firefox

Also: Preferences → Performance → uncheck "Use recommended performance settings" → set to "Use hardware acceleration when available".

  1. Safari uses hardware acceleration automatically — no toggle needed
  2. If not working: Safari → Settings → Advanced → check "Show features for web developers"
  3. Open Develop → Experimental Features → ensure WebGL 2.0 is enabled
  4. Restart Safari

On older Macs: Software Update → install latest macOS. WebGL requires GPU driver support which older macOS versions may lack.

Where does WorldIntelligence get its data?

All 23 datasets are sourced from verified open intelligence feeds: OpenStreetMap, ACLED, IAEA PRIS, Sentinel-2 Copernicus, GDELT Project, FlightAware, AIS maritime data, World Bank indicators, and USGS earthquake data. Every source is publicly documented and linked inside the console. See the full list at our data sources page.

How often is the data updated?

Most datasets refresh hourly. Satellite imagery updates daily via Sentinel-2 passes. Conflict events from ACLED are ingested in real-time. Nuclear facility status syncs with IAEA PRIS weekly. Every layer shows its last-updated timestamp inside the console — try it now.

Is WorldIntelligence free to use?

The console is completely free for everyone — researchers, journalists, analysts, and institutions. No signup, no paywall, no card required. The REST API is also free with 1,000 requests/hour. CSV and JSON export built in.

Can I use WorldIntelligence data in my own application?

Yes. REST API with GeoJSON responses. 1,000 requests/hour, no key required. Read the API docs.

What mapping technology does the console use?

The console runs Leaflet for 2D mapping and CesiumJS for 3D globe visualization. Both are open-source. Base maps use OpenStreetMap tiles. Custom overlays render as GeoJSON layers on top of the base map. Learn more at our console.
